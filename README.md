# 🐉 Розовая виверна: Симулятор полёта

Браузерная аркада на чистом HTML+JS: управляй розовой виверной, взмахивай крыльями и собирай золотые кольца над облаками.

**Играть:** открой `index.html` или включи GitHub Pages в Settings → Pages.

- **↑ / ▲** — взмах вверх
- **Пробел / 🞂** — резкий взлёт
- **↓ / ▼** — планирование вниз
- **F / 🔥** — огненное дыхание: сжигает скалы (перезарядка 3 с)

На пути попадаются скалы и столбы — столкновение отнимает одно из трёх сердец, но их можно испепелить пламенем!
